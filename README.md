# Monolithic

The public landing page for [Monolithic](https://monolithicmfg.com/).

Static HTML, CSS, and JavaScript. No dependencies or build step.

## Local preview

```sh
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000`.

## Publishing

GitHub Pages publishes the repository root from `main`. `CNAME` specifies the production domain.
